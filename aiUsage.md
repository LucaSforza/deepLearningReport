# AI usage for Deep Learning

We did not use AI for:

- Writing the report content.
- Looking for the sources.
- Studying the sources.

We used AI for the following tasks:

- Formalizing the gas cost function found inside of the report and this was
  followed by a comprehensive human evaluation of the formalization.
- Help writing the code of the following repos:
  - git_diff_checker
  - git_diff_checker/hooks
  - mcp_synth
  - queue_controller

But this code was not vibe-coded we had [intent](https://noperator.dev/posts/you-can-just-say-it/) while writing it and we know how each component works and the parts which make them.
We designed the application exactly how we explained inside of the report,
we followed the SW development cycle.
